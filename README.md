# teams-cli

CLI para Microsoft Teams web inspirada no wacli.

Direção: TypeScript/Node.js, sessão persistente, sincronização para SQLite com FTS5, busca local e envio para chats, grupos e canais.

Preferência de autenticação: device code, se compatível com os endpoints necessários; alternativa headless. Validar antes da implementação completa.

Documentação do projeto: vault Obsidian, área pessoal.teams-cli (pessoal/teams-cli/notes.md).

Estado: planejamento; sem implementação ou autenticação configurada.
