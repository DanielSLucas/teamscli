# teams-cli

CLI open source para Microsoft Teams web, equivalente ao wacli: dê aos seus agentes acesso ao Teams.

Direção: TypeScript/Node.js, sessão persistente, sincronização para SQLite com FTS5, busca local e envio para chats, grupos e canais.

Autenticação: device code, sem senha e sem navegador. Somente endpoints do Teams web; sem Microsoft Graph.

Documentação do projeto: vault Obsidian, área pessoal.teams-cli (pessoal/teams-cli/notes.md).

Estado: autenticação (device code) e endpoints do Teams web validados por spikes; implementação não iniciada. Ver `docs/authentication.md`.
